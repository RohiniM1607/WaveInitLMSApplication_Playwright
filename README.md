Waveinit LMS
    Waveinit LMS is a Learning Management System (LMS) application designed to help trainers manage learning content and participants access and complete their training.

Application URL: https://www.waveinitlms.online/

User Roles
The application has two main user roles:

1. Trainer - The trainer can manage the learning activities in the application.

Main activities:
Login to the application
Manage courses
Manage learning content
Manage participants
Create and manage assessments
Monitor participant progress

2. Participant - The participant uses the application to access and complete the assigned training.

Main activities:
Login to the application
View available courses
Access course content
Attend/complete learning activities
Take assessments
Track learning progress
